⏳ Buscando deudas...
¿Como se si tengo deudas? ▼
Ingresa tu DNI en el campo de arriba y presiona Consultar. El sistema buscara automaticamente si tenes deudas registradas en nuestra base de datos.
¿Que hago si tengo una deuda? ▼
Si tenes deudas, vas a ver el detalle de cada una y el monto total. Luego podes elegir entre Mercado Pago o Transferencia para realizar el pago.
¿Como reporto que ya pague? ▼
Despues de realizar el pago, presiona el boton 📢 ¿Ya pagaste? Reporta tu pago. Completa el formulario con tus datos y el comprobante. El administrador lo verificara y te confirmara.
¿Que datos necesito para reportar? ▼
Necesitas:
• DNI (se completa automaticamente)
• Nombre completo
• Monto que pagaste
• WhatsApp (para que te contactemos)
• Comprobante de pago (opcional, pero recomendado)
¿Cuanto tarda la verificacion? ▼
El administrador verifica los pagos a la brevedad. Una vez verificado, recibiras la confirmacion. El tiempo puede variar segun la disponibilidad del equipo.
¿Que pasa si no encuentro mi deuda? ▼
Si no encontras tu deuda, puede que:
• No tengas deudas registradas
• El DNI ingresado sea incorrecto
• La base de datos no este actualizada
En cualquier caso, podes contactar a soporte para mas informacion.
¿Es seguro ingresar mi DNI? ▼
Si. Solo usamos tu DNI para consultar tu situacion en nuestra base de datos. No almacenamos informacion personal ni compartimos tus datos con terceros.
❌ No se pudo cargar el archivo de deudas.
Verifica que el archivo deudas.csv este en el mismo directorio.
